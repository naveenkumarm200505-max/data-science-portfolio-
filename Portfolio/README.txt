# NAVEEN KUMAR M — Premium Data Science Portfolio

## Run locally
Open `index.html` in Chrome/Edge.

## Included
- Premium dark navy/black SaaS-style portfolio
- Responsive desktop/tablet/mobile layout
- Animated hero, reveal effects and KPI counters
- Interactive Chart.js analytics dashboard
- Projects, skills, learning timeline, resume preview, GitHub and contact sections
- Resume PDF included as `Naveen_Kumar_M_Resume.pdf`

## Customize
1. Replace the profile placeholder in the hero with your photo.
2. Replace project GitHub/Live Demo placeholders with individual URLs.
3. Upload to GitHub Pages, Netlify, Vercel or another static host.
